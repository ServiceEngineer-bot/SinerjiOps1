## 🚀 Installation et utilisation

### Option 1 : Utilisation directe
1. Téléchargez tous les fichiers
2. Ouvrez `clean-version.html` dans votre navigateur
3. Utilisez les comptes de test ou créez un nouveau compte

### Option 2 : GitHub Pages
1. Allez dans Settings > Pages de votre repository
2. Source : "Deploy from a branch"
3. Branch : "main"
4. Folder : "/ (root)"
5. Cliquez "Save"

## 🔧 Configuration GitHub Pages

Pour que l'application s'affiche automatiquement :

1. **Allez dans votre repository GitHub**
2. **Cliquez sur "Settings"**
3. **Dans le menu de gauche, cliquez sur "Pages"**
4. **Source :** Sélectionnez "Deploy from a branch"
5. **Branch :** Sélectionnez "main"
6. **Folder :** Sélectionnez "/ (root)"
7. **Cliquez "Save"**

Après quelques minutes, votre application sera accessible à :
`https://votre-username.github.io/sinerjiops-maintenance/clean-version.html`
